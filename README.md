# **Vercel_Deploy**
### **Climate Data Visualization Dashboard**

---

## **Project Overview**

This project is a **React-based web application** designed to visualize climate data using the **Plotly library**. The main objective is to integrate interactive charts into a seamless React environment, allowing users to interact with multiple datasets through a **component-based navigation system**.

The application features a side navigation bar that allows users to toggle between different climate data visualizations, such as **temperature trends** and **precipitation analysis**.

---

## **Features**

* **Interactive Visualizations**: High-quality integration of **Plotly.js** for interactive climate charts.
* **Dynamic Navigation**: A list-based scheme to switch between visualizations without page reloads.
* **Modern Tech Stack**: Developed using **Vite** and **React** for optimal speed and performance.
* **Responsive Design**: Layout structured to handle data frames and sidebars effectively.

---

## **Technologies Used**

* **React**: Front-end library for building the user interface.
* **Plotly.js**: JavaScript graphing library for advanced data visualization.
* **Vite**: Build tool and modern development server.
* **CSS3**: Custom styling for a clean dashboard layout.
* **Vercel**: Platform used for hosting and production deployment.

---

## **Installation and Setup**

Follow these steps to set up the project locally:

1.  **Clone the repository**:
    ```bash
    git clone [https://github.com/ImZange/Vercel_Deploy.git](https://github.com/ImZange/Vercel_Deploy.git)
    cd Vercel_Deploy
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```

4.  **Build for production**:
    ```bash
    npm run build
    ```

---

## **Deployment**

This project is configured for deployment on **Vercel**. To perform your own deployment:

1.  Push the code to your **GitHub** repository.
2.  Connect the repository to your **Vercel** account.
3.  Add the required environment variable: `NEXTAUTH_SECRET`.
4.  Click **Deploy** and access the generated URL.
