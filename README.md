Vercel_Deploy: Climate Data Visualization
This project is a React-based web application designed to visualize climate data using the Plotly library. It allows users to interact with multiple datasets through a component-based navigation system.

Project Overview
The main objective of this application is to integrate interactive charts generated with Plotly into a seamless React environment. The app features a side navigation bar that allows users to toggle between different climate data visualizations, such as temperature trends and precipitation analysis.

Features
Interactive Visualizations: Integration of Plotly.js for high-quality, interactive climate charts.

Dynamic Navigation: A list-based navigation scheme to switch between visualizations without page reloads.

Modern Tech Stack: Built with Vite and React for optimal development speed and performance.

Responsive Design: Layout structured to handle data frames and sidebars effectively.

Technologies Used
React: Front-end library for building the user interface.

Plotly.js: JavaScript graphing library for data visualization.

Vite: Build tool and development server.

CSS3: Custom styling for the dashboard layout.

Vercel: Platform used for hosting and deployment.

Installation and Setup
Clone the repository:

Bash
git clone https://github.com/ImZange/Vercel_Deploy.git
cd Vercel_Deploy
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
Build for production:

Bash
    npm run build
    ```

## Deployment

This project is configured for deployment on Vercel. To deploy your own version:

1.  Push the code to your GitHub repository.
2.  Connect the repository to your Vercel account.
3.  Add the required environment variable: `NEXTAUTH_SECRET`.
4.  Deploy and access the live URL.
